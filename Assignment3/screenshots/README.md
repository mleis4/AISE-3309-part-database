# Screenshots for the Assignment 3 report

_Generated by `build_report.py`. Do not edit by hand._

The report already shows every statement's response as text (recorded by `capture_responses.py`). These 21 Workbench screenshots are the evidence that the statements were run in MySQL Workbench: about one per handout requirement, not one per statement.

## How to take them

1. In Workbench, open each SQL file and run the whole script (lightning-bolt button). For task7.sql and task8.sql, first turn on *Edit > Preferences > SQL Editor > Continue SQL script execution on errors*, because some statements fail on purpose.
2. Run the files in this order on an empty `ep_sourcer` schema: task3.sql, task4.sql, SRC/load_data.sql, SRC/check_data.sql, task6.sql, task7.sql, task8.sql.
3. **Action Output** (bottom panel) lists the response of every statement in the script. One screenshot of it covers a whole file. If it needs scrolling, save the extra parts as `<name>_2.png`, `<name>_3.png`, and the report embeds them in order.
4. **Result grids**: each SELECT opens a result tab. Click the tab you need and capture the query together with its grid.
5. Save each PNG here with exactly the name below, then run `python build_report.py`.
